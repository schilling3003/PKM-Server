### Failed scenario details: OKF wikilink round-trip

**Reproduction**

1. Create a workspace and a document whose canonical content contains a wikilink:
   ```bash
   POST /workspaces/:id/documents
   { "path": "source.md", "content": "---\ntype: Note\n---\n\nSee [[another]]." }
   ```
2. Export the workspace:
   ```bash
   GET /workspaces/:id/okf/export
   ```
3. Re-import the exported bundle into the same workspace:
   ```bash
   POST /workspaces/:id/okf/import
   <exported JSON>
   ```

**Expected:** `content` and `content_hash` of `source.md` are unchanged (canonical Markdown preservation).

**Actual:** `source.md` content changes from
```
---
type: Note
---

See [[another]].
```
to
```
---
type: Note
---

See [another](another.md).
```

**Root cause code path**

- `apps/api/src/okf.ts:51` — `importOkf` always calls `wikiToStandard(body)`, converting `[[...]]` to standard Markdown.
- `apps/api/src/okf.ts:94` — `exportOkf` calls `standardToWiki(parsed.body)`, which only converts `[text](target.md)` back to wikilinks. It leaves an already-wikilink canonical body unchanged.

The result is an asymmetric cycle: export preserves `[[another]]`, re-import rewrites it to `[another](another.md)`. This violates the AGENTS.md invariant that canonical Markdown must be preserved through import/export round-trips.

**Recommendation:** Decide whether canonical storage uses standard Markdown links (and normalize wikilinks on create/update) or wikilinks (and make `exportOkf`/`importOkf` idempotent). Because the existing `apps/api/test/integration.test.ts` OKF v0.2 test expects standard canonical and wikilink OKF bodies, the design appears to be standard canonical; the web and API document create/update paths are not normalizing wikilinks before storage. This is a cross-cutting product decision, so no fix branch was opened for this report.

## Appendix: API end-to-end test script

```bash
#!/usr/bin/env bash
set -euo pipefail
API="http://127.0.0.1:4000"
AI="http://127.0.0.1:8000"
LOG=/tmp/pkm_api_e2e.log
exec > >(tee -a "$LOG") 2>&1

PASS=0
FAIL=0
ok() { echo "PASS: $1"; PASS=$((PASS+1)); }
ko() { echo "FAIL: $1"; FAIL=$((FAIL+1)); }

echo "=== PKM v1 API end-to-end scenarios ==="
echo "$(date -u +%Y-%m-%dT%H:%M:%SZ)"
echo "API health: $(curl -s "$API/health")"
echo "AI health: $(curl -s "$AI/health")"

# Create workspaces
WS_A=$(curl -s -X POST "$API/workspaces" -H 'Content-Type: application/json' -d '{"name":"Workspace A"}' | jq -r '.id')
WS_B=$(curl -s -X POST "$API/workspaces" -H 'Content-Type: application/json' -d '{"name":"Workspace B"}' | jq -r '.id')
echo "Workspace A id: $WS_A"
echo "Workspace B id: $WS_B"

# Create overlapping notes
NOTE_A=$(curl -s -X POST "$API/workspaces/$WS_A/documents" -H 'Content-Type: application/json' -d '{"path":"alpha-note.md","content":"---\ntype: Note\n---\n\nProject alpha details for workspace A."}' | jq -r '.id')
NOTE_B=$(curl -s -X POST "$API/workspaces/$WS_B/documents" -H 'Content-Type: application/json' -d '{"path":"alpha-note.md","content":"---\ntype: Note\n---\n\nProject alpha analysis in workspace B."}' | jq -r '.id')
echo "A note id: $NOTE_A"
echo "B note id: $NOTE_B"

# Search in A
SEARCH_A=$(curl -s -G "$API/workspaces/$WS_A/search" --data-urlencode 'q=alpha')
echo "$SEARCH_A" | jq -e 'length == 1 and .[0].workspace_id == '"$WS_A"'' && ok "Search in A returns exactly one A note" || ko "Search in A leaked B note"

# Ask in A
ASK_A=$(curl -s -X POST "$API/workspaces/$WS_A/ask" -H 'Content-Type: application/json' -d '{"question":"What is alpha?"}')
echo "$ASK_A" | jq -e '.citations | length == 1' && ok "Ask A cites A note" || ko "Ask A citation count wrong"

# Ask in B
ASK_B=$(curl -s -X POST "$API/workspaces/$WS_B/ask" -H 'Content-Type: application/json' -d '{"question":"What is alpha?"}')
echo "$ASK_B" | jq -e '.citations | length == 1' && ok "Ask B cites B note" || ko "Ask B citation count wrong"

# Backlinks in A
SOURCE_A=$(curl -s -X POST "$API/workspaces/$WS_A/documents" -H 'Content-Type: application/json' -d '{"path":"source.md","content":"---\ntype: Note\n---\n\nSee [[another]]."}' | jq -r '.id')
TARGET_A=$(curl -s -X POST "$API/workspaces/$WS_A/documents" -H 'Content-Type: application/json' -d '{"path":"another.md","content":"---\ntype: Note\n---\n\nTarget note in A."}' | jq -r '.id')
OUT_A=$(curl -s "$API/workspaces/$WS_A/documents/$SOURCE_A/links")
BL_A=$(curl -s "$API/workspaces/$WS_A/documents/$TARGET_A/backlinks")
echo "$OUT_A" | jq -e '(.[0].id == '"$TARGET_A"')' && ok "A wikilink resolves and backlink recorded" || ko "A wikilink/backlink broken"

# Backlinks in B (isolation)
SOURCE_B=$(curl -s -X POST "$API/workspaces/$WS_B/documents" -H 'Content-Type: application/json' -d '{"path":"source.md","content":"---\ntype: Note\n---\n\nSee [[another]]."}' | jq -r '.id')
TARGET_B=$(curl -s -X POST "$API/workspaces/$WS_B/documents" -H 'Content-Type: application/json' -d '{"path":"another.md","content":"---\ntype: Note\n---\n\nTarget note in B."}' | jq -r '.id')
OUT_B=$(curl -s "$API/workspaces/$WS_B/documents/$SOURCE_B/links")
BL_B=$(curl -s "$API/workspaces/$WS_B/documents/$TARGET_B/backlinks")
echo "$BL_B" | jq -e 'map(.path) | contains(["source.md"])' && ok "B backlinks do not include A source" || ko "B backlink isolation broken"

# OKF export
EXPORT=$(curl -s "$API/workspaces/$WS_A/okf/export")
echo "$EXPORT" | jq -e '.version == "0.2" and (.concepts | length) == 3' && ok "Export has version and concepts" || ko "Export structure wrong"

# Re-import
REIMPORT=$(curl -s -X POST "$API/workspaces/$WS_A/okf/import" -H 'Content-Type: application/json' -d "$EXPORT")
BEFORE=$(curl -s "$API/workspaces/$WS_A/documents" | jq 'sort_by(.path)')
AFTER=$(echo "$REIMPORT" | jq '.concepts | sort_by(.path)')
DIFF=$(diff <(echo "$BEFORE") <(echo "$AFTER") || true)
if [ -z "$DIFF" ]; then
  ok "Re-import leaves canonical content unchanged"
else
  ko "Canonical content changed after OKF re-import"
  echo "$DIFF"
fi

echo "=== Done ==="
echo "PASS=$PASS FAIL=$FAIL"
```
